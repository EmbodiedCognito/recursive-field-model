World Assembly Model v0.1

A substrate-first perturbation model. Relations are enacted by explicit message channels; history may alter later susceptibility. The model has no reward, target, object labels, agent labels, classifier, or preferred outcome.

Local transition law

Positive adaptation sensitises with retained interaction history; negative adaptation habituates. Neither direction is treated as privileged.

External relational probe

The probe forks the present state outside the developmental process. It measures whether a perturbation creates downstream differences, then whether prior perturbation changes the effect of an otherwise identical later probe.
